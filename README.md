# Aro · Análisis de básquet

Análisis de partidos de básquet a partir del video: etiquetado de jugadas con el teclado, box score, mapa de tiros, mapa de calor, evolución del marcador, impacto por jugador y mejores momentos. Cada jugada salta al segundo exacto del video de YouTube.

- `index.html`: la aplicación completa (un solo archivo).
- `partidos/`: partidos incluidos con la aplicación.

La nube (Supabase) se activa completando `CONFIG` al principio del script de `index.html`.
